# Group Project – Data Science Challenge

## Overview

This repository contains the work completed by our team as part of the Data Science Challenge Hackathon for the Research Methods module at the University of Hertfordshire.

The objective of the challenge was to develop machine learning models capable of predicting the target variable from a provided dataset. The project involved collaborative data exploration, preprocessing, model development, evaluation, and submission of predictions for the competition leaderboard.

---

## Team Information

**Module:** Research Methods in Data Science

**Project:** Data Science Challenge Hackathon

**University:** University of Hertfordshire

**Team:** Group C

---

## Project Workflow

The project followed a standard data science pipeline:

1. Data Exploration and Understanding
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Model Development
5. Model Evaluation
6. Ensemble Learning
7. Test Set Prediction Generation
8. Competition Submission

Version control and collaboration were managed using GitHub and Google Colab.

---

## Models Developed

The following machine learning models were implemented and evaluated:

* Logistic Regression
* Random Forest Classifier
* XGBoost Classifier
* LightGBM Classifier
* Ensemble Model (Voting/Stacking)

The final submissions were ranked according to validation performance and submitted from best to worst model.

## Results

Multiple machine learning models were trained and evaluated using validation metrics. The best-performing models were selected for competition submission. Five prediction files were generated and ranked according to performance.
